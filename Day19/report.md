## 💡 Key Learnings

### What I Built
A 4-stage interactive Football Intelligence Hub that:
- **Adapts to the user's knowledge level** (5 tiers from Beginner to Analyst)
- **Generates personalized World Cup 2026 predictions** with confidence scores, evidence, and risks
- **Scores Football IQ** across history, players, tactics, and analytics
- **Maps personality to Messi or Ronaldo** across 10 dimensions without asking directly
- **Assigns a Football Personality Archetype** from 5 distinct types
- **Generates a unified profile** with player, club, team, and rivalry recommendations

### What I Learned About AI Prompting
1. **Multi-stage prompting** works best when each stage builds on the previous output — the knowledge level check in Stage 0 changes every subsequent answer
2. **Personality assessment without direct questions** is a powerful design pattern — never asking "are you like Messi or Ronaldo" but mapping natural traits to football legends
3. **Confidence scores make AI predictions trustworthy** — showing 72% vs 65% vs 45% feels honest rather than claiming certainty
4. **Adaptive depth is key** — the same World Cup prediction reads differently for a beginner vs an analyst; this is what makes AI tools genuinely useful
5. **Football data is a perfect AI use case** — rich historical data, quantifiable metrics (xG, PPDA), and strong narrative potential combine into compelling, evidence-based analysis

### Technical Highlights
- Pure HTML/CSS/JS — no external dependencies, fully offline-capable
- State machine pattern for stage management
- Dynamic quiz generation based on knowledge level
- Weighted personality scoring algorithm (Messi/Ronaldo trait mapping)
- Responsive design with CSS custom properties for consistent theming
- Animated stage transitions with CSS keyframes
